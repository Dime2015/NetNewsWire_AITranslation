# Reference Concept · Soft Shell

## 风格提炼

这套方案没有照搬三张参考图中的具体控件，而是提取了能够迁移到 RSS 阅读器的共同规则：页面主体依靠留白、字号和分隔线形成连续层级，只有底部操作区与临时菜单保留柔白外壳，内部以更亮的胶囊表示当前选择，高饱和橙色只标记当前动作，图标采用圆角粗线并减少文字标签。

## 在 Babel 中的对应关系

- 参考图中的底部导航外壳，被转换为 Babel 的主页、搜索、稍后读和设置导航。
- 参考图中的双段切换器，被转换为星标、未读、全部，以及全局目标语言状态。
- 参考图中的浮动菜单，被转换为文章操作菜单和推荐反馈菜单。
- 参考图中的橙色选中态，被用于当前阅读筛选、翻译动作和设置入口。
- 主页头部、文章列表、文章正文和设置分组全部保持平面连续，只在底部操作区和临时弹出菜单使用立体效果，避免页面被切成许多卡片。

## 与旧方案的主要区别

旧方案用衬线字体、纸张和编辑标记建立气质；新方案完全转向系统无衬线字体、圆角外壳与触感更强的原生控件。品牌识别不再依赖浮世绘或校样符号，而来自灰白物理表面、粗线图标和橙色动作反馈。信息密度仍然遵守现有 App 的真实需求，不为了模仿参考图而把订阅源、文章摘要和设置结构删掉。

## 建议进入下一轮时验证

这套风格最需要验证的是阴影强度和可访问性。真实设备上应分别测试普通显示、降低透明度、增强对比度、深色模式和动态字体；如果外壳边缘在低亮度下变得不清楚，应优先增加轮廓对比，而不是继续加重阴影。
