# Babel Design Workspace

这个文件夹已经整理为一个明确的当前方案、一个历史归档区和一套研究资料。其他 AI 应以 `current/` 为唯一设计源，不要从 `archive/` 中混合旧视觉语言，除非用户明确要求回看上一轮。

## 从这里开始

1. 打开 `current/HANDOFF.md`，了解产品约束、视觉语言和文件用途。
2. 双击根目录的 `index.html`，或直接打开 `current/index.html` 查看交互稿。
3. 使用 `current/assets/screens/` 中的 12 张 Light / Dark 高保真 PNG 作为视觉依据。
4. 使用 `current/assets/references/` 中的三张原始参考图理解风格来源。

## 目录

- `current/`：当前 Soft Shell 设计的完整、自包含工作包。
- `archive/`：此前 A / B / C 编辑排版方向、旧图标、旧长图和旧评审 PDF。
- `research/`：DESIGN-BRIEF、设计问卷和现有 App 截图等输入资料。
- `reference-concept/`：兼容旧链接的跳转页，实际内容在 `current/`。

当前方案没有修改 App 源代码。所有设计稿、参考图、说明与可编辑网页源文件均位于 `Design/` 内。
