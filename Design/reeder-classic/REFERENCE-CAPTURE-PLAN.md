## iPhone 17 固定基准

第一套复刻基准固定为：

1. 纵向 iPhone 17，系统默认显示缩放。
2. 系统文字大小保持默认中间值；关闭“更大字体”。
3. Reeder 的主题分别固定为 Light 和 Dark，不使用自动切换。
4. 保持系统状态栏、动态岛和底部 Home 指示条可见。
5. 不裁切、不压缩、不加标注；原始 PNG 作为证据，测量副本另存。
6. 录屏每个动作前后各停留约 1 秒，保证能看到起始态和结束态。

## 组件库筛选结论

本项目是原生 iOS Swift 工程。当前候选库不能直接作为生产 UI 依赖：

- beUI Pro：React / Next.js / Tailwind / Motion，适合 Web 动效参考。
- BoardUI：React + Tailwind 的后台和数据组件，信息架构与 Babel 不匹配。
- ThreeUI：若采用其 Three.js / WebGL 路线，会把原生阅读器变成网页壳，暂不采用。
- Fluid Functionalism：设计与动效方法论 / shadcn 生态，不是 UIKit 组件库。
- Watermelon UI：目前没有足够的官方原生 iOS 资料，不在第一轮引入。
- HeroUI / HeroUI Pro：提供 React 与 React Native；把 Babel 改成 React Native 会扩大构建和数据接入风险。

结论：第一轮母版使用 UIKit 原生控件和项目内自有样式层；组件库只可在不改变原生架构的前提下提供动效或交互启发。任何引入都必须先记录许可证、依赖、包体积和可复现构建结果。

## 验收边界

- 视频帧可以支持代码实现和静态叠图，但不能替代用户在 iPhone 17 上对手感、滚动和转场的最终验收。
- 没有对应参考帧的页面不宣称“像素级复刻”。
- 首页、文章时间线、文章阅读页的浅色和深色母版先独立完成；通过用户真机验收后再接入真实数据和翻译动作。
