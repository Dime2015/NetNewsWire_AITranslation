# Babel 2.0 统一图标集 · 设计要求（2026-09-27）

## 用户原话

> 现在 app 里的各种 icon（设置页菜单前的 icon、长按弹出菜单里的各种 icon、底栏的 icon）给我一种设计 / 粗细 / 视觉重心 / 风格都不统一的感觉。设置里的 icon 都挺复杂，底栏的 icon 又很简单，长按弹出菜单里的各种 icon 又很细，并且有点复杂。
> 画一整套，包含全部这个 app 里涉及到的语义的，**稍微粗一点，小一点，设计风格统一，现代，克制，甚至有点抽象（以简单线条和几何图形为主）**的 icon 集。
> 记住，画 icon 时，我要那种**特别高级的审美**。

对第一稿（translate = 方块里一个 A + 后面半个方块；long-image = 竖长框里一张风景照；chat = 带尾巴的气泡里三个点；star-off = 星星加斜杠）的评价：**「还是有点过于卡通了，过于拟物，过于复杂了」**。

## 现状（为什么不统一）

- 设置分类：系统图标（person.crop.circle、dot.radiowaves、list.bullet、doc.plaintext、circle.lefthalf.filled、bell、questionmark.circle）+ 一个实心文字图形「翻译」——细节多、线细。
- 长按 / 「•••」菜单：全是系统细线图标（pencil、trash、photo、arrow.uturn.backward、doc.on.doc、safari、shield……）。
- 底栏：设计稿 24 格 SVG，线宽 1.53 / 1.8 / 2.925 不等，极简。
- App 的品牌气质：App 图标是报纸 / 编辑部风格——粗衬线「B.」、右下一个小红点、背景是细密的报纸栏。纸色底（浅 #F5F2F1 / 深 #1C1C1C）、墨色字、次要灰；整体克制、编辑感、少颜色。

## 硬性约束

- 全套 47 个语义，名字 / 含义 / 用处固定（见 `icons.py` 里每个 `icon(...)` 的前三个参数与分组），**一个都不能少、不能改名**。
- 画布 24×24；外层 `<svg>` 统一 `fill="none" stroke="currentColor" stroke-width=STROKE stroke-linecap="round" stroke-linejoin="round"`；需要填实的部分写 `fill="currentColor" stroke="none"`。
- App 里按**模板图**单色上色：**不能用背景色去「盖」出空隙**；要镂空必须用 `<mask>`（id 全套唯一）。
- 状态必须一眼可分：read-off（空心）/ read-on（实心）；star / star-on（实心）/ star-off；subscribe / subscribed（实心 + 镂空勾）；unread-dot 是「● UNREAD」胶囊里的小实心点。
- **reader-mode 固定为「四道横线、最后一道短」**（用户在 ADR-049 亲自定过，去掉了外框），只允许按新体系调粗细和比例。
- translate：用户在 ADR-049 选回了系统「文 / A」翻译符号；新设计可以给一个同体系的候选，但 App 会在它**右下角画一个 6×6pt 左右的小圆点**（实心 = 有整篇译文缓存，空心 = 翻了一半），右下角要留得出位置。
- sync（同步中）会**原地旋转**：造型要适合转动（圆弧类，重心在圆心）。refresh 与 sync 同一构造。
- chevron（back / forward / chevron-down）同一个角度与臂长，只是方向不同；check 同一个造型用于菜单勾、设置单选、保存。
- 实际显示尺寸：底栏约 21pt、菜单 18pt、设置 20pt、首页入口 15pt；深浅两种底色。

## 质量标准（用户要的「高级」）

- **一套构造语法**：同样的线宽、同样的端点（圆头）、同样的圆角半径、同样的角度（以 45° / 90° 为主），同一类外形用同一组关键尺寸（例如圆 Ø17、方 15、竖框 13×17、横框 17×13），视觉重量一致。
- **小一点**：主体收在画布中间约 16–18 的范围，四周留白充足；**稍微粗一点**：比现在菜单里的系统细线图标粗一档，但不能笨。
- **抽象、克制**：每个图标只保留最能说明语义的一两个元素；框里不塞细节；不画插画式的物件（照片、风景、手机、人脸、气泡里的点点）；宁可更抽象一点，也不要可爱、卡通、拟物。
- **负空间与开口**：优先用开放的形（缺口、半框），让图标「透气」。
- 线条坐标落在 .0 / .5 上，20px 实际大小下清晰、不糊。
- 参考水准：Linear、Things 3、Reeder、Craft、Apple 自家最好的那部分图形——但要有自己的一致性，不是拼凑。
- 反例（不要）：剪贴画感、同一套里有的圆润有的锐利、箭头大小不一、框里画小装饰、用很多短线凑细节（例如太阳的 8 根光线要慎重）。

## 检查方法

`python3 <scratchpad>/icons/sheet.py <icons.py> <out.png> [--only a,b]` 生成检查图：真实场景（阅读页底栏、长按菜单、设置分类、首页入口，浅 / 深）+ 每个图标的放大 / 40px / 20px。以 20px 实际大小和场景里的整体一致性为准。
