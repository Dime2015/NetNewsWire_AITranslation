## 三个方向

### A · 安静的编辑排版

几乎不使用图像，依靠中西文排版、纸张层次、留白与克制的陶土色建立产品识别。优点是成熟、安静、内容优先；风险是与其他高质量阅读器的区分度较弱。

### B · 图像只留在门口

保留现有浮世绘所代表的情绪资产，但只让图像出现在主页、空状态和引导时刻。进入文章列表和阅读后，图像退场。优点是亲和、延续性强；风险是品牌仍然容易被理解成偏东亚文化产品。

### C · 译者的校样桌（推荐）

使用校样线、裁切标、批注与双语结构建立身份。它不是把“翻译”做成一个醒目的附加功能，而是让整个阅读界面像一个为跨语言阅读准备的编辑工作台。优点是产品特征最强、全球化范围更自然；风险是需要严格控制红色标记的数量，避免显得忙乱。

## 文件结构

- `prototype-static/`：本地交互评审页

## 建议的评审顺序

1. 在交互页切换 A / B / C，先只看主页、文章列表和文章内容。
2. 固定为 C，依次查看原文、翻译中、已翻译、停靠状态。
3. 比较“重复订阅源名”和“弱化翻译键”两个 A/B 开关。
4. 查看设置、长图和图标。
5. 最后打开压力测试，切换深色和动态字体。

## 本轮建议

以 C 为主方向进入第二轮，但吸收 A 的安静排版纪律和 B 的“图像只留在入口”原则：

- 阅读内容区采用 C 的校样结构，但标记密度向 A 靠拢。
- 首页可以保留一处 B 式情绪图像，列表和文章中不再使用。
- 图标优先继续迭代 C；B 作为更亲和的备选。
- 单源列表默认不重复订阅源名称。
- 目标语言文章保留翻译动作，但默认弱化。
